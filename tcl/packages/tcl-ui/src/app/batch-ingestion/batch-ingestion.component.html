help_outline What's supported?

File Types

  • Archives: .zip (recommended)
  • Text formats: .txt, .json, .jsonl, .csv
  • Subtitle formats: .vtt, .srt
  • Audio formats: .mp3, .wav, .m4a, .flac, .ogg, .opus

CSV Contracts

Turn-Level CSV (Recommended):

  • Required columns: conversation_id, turn_index, text
  • Optional columns: speaker, timestamp, channel

JSONL Format

Each line is a JSON object. Supports:

  • Canonical schema (turns array with speaker_raw, text)
  • Minimal schema (text field with optional speaker, conversation_id)

ZIP Files

ZIP files can contain:

  • Transcripts: .txt, .json, .jsonl, .vtt, .srt
  • Audio: .wav, .mp3, .flac, .m4a, .ogg, .opus
  • Metadata: .csv, .json

Audio and transcript files are automatically paired by basename (e.g., call_123.wav pairs with call_123.txt).
