About Audit Packs

Audit packs provide a defensible export bundle for compliance purposes, including:

  • PDF Report: Executive summary, top issues with score breakdowns, evidence quotes, and run integrity information
  • JSON Export: Complete IssueV2 array with scoring components and reasons
  • CSV Export: Flattened issue rows for analysis in spreadsheet tools

All files include traceability information (input hash, config hash, engine version) for reproducibility.
