# Agent Rules

## Safety Rules

- Do not expose secrets.
- Do not bypass permissions.
- Do not run unsafe tools without approval.
- Do not modify unrelated files.
- Do not perform destructive actions without explicit approval.

## Quality Rules

- Follow existing project patterns.
- Prefer small, reviewable changes.
- Validate work against acceptance criteria.
- Include tests or explain why tests were not added.

## Collaboration Rules

- Log blockers.
- Request review when needed.
- Update shared context when work changes team state.
