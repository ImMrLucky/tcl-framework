# `agent-mcp`

Model Context Protocol (MCP) server descriptors + client contract for
**Agent Studio**.

The MVP only persists MCP server CRUD (transport, command, args, env, headers,
enabled tools). Spinning up MCP clients and proxying tool calls is the next
iteration.

> **Status:** MVP scaffold. Types only.

See [`docs/specs/agent-studio.md`](../../docs/specs/agent-studio.md).
